# CANdor – Handy-Vorschau

Installierbare Web-App der KFZ-Diagnose CANdor, erzeugt mit `tools/web_app.py` aus dem Hauptprojekt.
Ohne Diagnose-Server startet sie mit synthetischen Beispieldaten. In Chrome auf Android kann sie sich per Bluetooth
mit einem OBD-Adapter verbinden und liest dann nur (keine Löschfunktionen, keine Stellglieder).

Auf dem iPhone: Seite in Safari öffnen, Teilen, »Zum Home-Bildschirm«.
